# 🛡️ Job Scam Detector Extension

🚀 A **Chrome Extension powered by Machine Learning & NLP** that detects fraudulent job postings in real-time and helps users avoid scams.

---

## 🌍 Problem Statement

Online job scams are rapidly increasing, targeting job seekers with fake opportunities to steal money or personal data.
These scams often mimic legitimate listings, making them difficult to detect manually.

Machine learning and NLP can be used to identify suspicious patterns in job descriptions and metadata ([GitHub][1]).

---

## 💡 Solution

This project provides a **browser-based extension** that analyzes job-related content and flags potential scams instantly.

👉 It works directly inside your browser, making detection:

* ⚡ Fast
* 🧠 Intelligent
* 🛡️ Real-time

---

## 🚀 Features

* 🔍 Real-time job scam detection
* 🧠 NLP-based text analysis
* 🚨 Alerts for suspicious job postings
* 🌐 Works directly in browser (Chrome Extension)
* ⚡ Lightweight and easy to use

Browser-based detection systems can classify content and alert users instantly during browsing, improving security awareness ([GitHub][2]).

---

## 🧠 How It Works

1. User visits a job posting
2. Extension extracts content
3. Text is analyzed using ML/NLP techniques
4. Model predicts:

   * ✅ Legitimate
   * ❌ Scam
5. User gets instant alert

## ⚙️ Installation (Chrome)

1. Clone the repo

```bash id="m1p2z7"
git clone https://github.com/Akashmdshetty/job-scam-detector-extension.git
```

2. Open Chrome
   👉 Go to: `chrome://extensions/`

3. Enable:
   👉 **Developer Mode**

4. Click:
   👉 **Load Unpacked**

5. Select the project folder

✅ Extension is now ready to use
